# 写剧本：六段留存结构怎么写

一次任务写一整支带货短剧（通常 30–90 秒，单产品）。你拿到 `research.json` 的拆解结论 + 用户的卖点，产出把 `drama.json` 的 `beats` 写满。

节拍流机制学自 shuohao-skills/novel-script（动作节拍 ↔ 台词行交替、时长确定性折算、钩子冷开场）；六段结构为本技能自研，专为留存指标设计。

## 六段结构与对应留存指标

| 顺序 | 段 id | 标签 | 优化指标 | 写什么 |
| --- | --- | --- | --- | --- |
| 1 | hook | 黄金3秒钩子 | **2秒不退** | 痛点 / 反常识 / 强冲突直击，把人摁住。**第一拍就给运动主体**，别用静物特写开场 |
| 2 | conflict | 放大冲突 | **5秒完播** | 把痛点放大成具体困境，制造共鸣（油腻、显老、费钱、麻烦…） |
| 3 | solution | 解法转折 | 完播钩子 | 抛出人设 / 悬念 / 反差，引出「其实有办法」 |
| 4 | product | 产品登场 | 卖点可视化 | 产品出场 + 核心卖点演示（一泵起泡、一擦即净…） |
| 5 | trust | 信任锚点 | 转化信任 | 效果对比 / 实测背书 / 价格锚点（原价→活动价） |
| 6 | cta | 升华+行动召唤 | 整体完播+转化 | 情绪升华 + 引导下单（点左下、今天有活动） |

## 硬规则

1. **时长预算先于一切。** 台词按 4.5 字/秒、动作按 2.5 秒/拍折算；写完跑 `validate` 看秒数。目标 45 秒约 12–16 个节拍。
2. **单句台词 ≤ 35 字，一口气说得完。** 长句拆两句，中间插一拍动作或反应。
3. **每个节拍标 `stage`**（六段之一），六段缺一不可——这是质量门 `six-stage`。
4. **钩子是动作不是标签**，落在全集前 3 拍（质量门 `hook-window`）。第一拍带主体运动：甩头、撕包装、泼水，别用「产品静物特写」开场。
5. **动作节拍一拍一件事、叙述体、常见动作优先**（AI 生成生命线，学自 novel-script）：
   - ✓ 常见动作：甩头、拧开瓶盖、抹上脸、递东西、点头、对比前后
   - ✗ 精巧物理：以寸计位移、微表情（睫毛颤）、比喻画面——改写或删
   - **动作里不许出现引号台词**（台词混进动作就没法计秒、没法喂 TTS）
6. **每两三轮流有画面动作**，别连说四句（演讲癖）。台词短、动作密。
7. **卖点可视化**：product 段必须把核心卖点变成「看得见的动作」（起泡、对比、一擦即净），不要只念参数。
8. **信任锚点具体**：用「第 3 天 vs 第 1 天」分屏对比、或「同事实测」背书、或「原价 99 今天 39」价格锚，别空喊「很好用」。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 开场死画面 | 第一拍是产品静物 | 换成运动中给（甩头/泼水/撕包装），产品挪到第 4 段出场 |
| 注水 | 寒暄、闲聊占一半 | 每拍要么推进冲突要么展示卖点 |
| 卖点悬空 | 只念参数不演示 | product 段加一个可见动作 |
| 六段缺一段 | 漏了 trust 或 cta | 质量门会拦，补上 |
| 钩子太晚 | 第 5 拍才抛冲突 | 钩子必须在前 3 拍 |
| 演讲癖 | 一个人连说四句 | 拆给对手或用动作打断 |
