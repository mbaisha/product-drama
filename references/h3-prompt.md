# H3 视频提示词 · 写法规范（可选，非强校验）

方法论学自 MiniMax-H3 官方提示词指南（I2VA / 多图对齐模式），内化成本技能自带文档——不依赖任何外部 skill。

> **本技能对 H3 提示词不做逐字对账**（这是相对 shuohao-skills 的关键提速点）。质量门只查「非空 + 含 `[Shot k]` 标记」。要接 MiniMax H3 / Seedance 实际生成时，照下面格式精修即可。

## 语言分工

- **默认整条中文**（`promptLang: 'zh'`）——带货短剧面向中文用户，中文提示词实测更稳。
- 台词保留原文；通用身份（一名年轻女性）替代角色名——H3 / Seedance 官方规范要求视频正文禁角色名。

## 结构

```text
参考图与目标视频的对齐——Picture 1（来自 Shot 1）对齐 0.00 秒；Picture 2（来自 Shot 2）对齐 3.00 秒；……

整体视听描述：
[镜头 1] 按 Picture 1 的构图锚定人物与产品状态，再写这几秒发生什么、镜头怎么动、谁说了什么。
[镜头 2] 于 00:03.000，镜头切到 Picture 2：……（每个镜头独立一行，切点时刻开头）

整体音景：1–4 句：环境声、动作声、非语言人声。不复述台词。

非剧情音乐：1–3 句写配器与速度；没有写「无」。
```

首行对齐指令和切点时刻**由分镜秒数推导**；改了秒数记得同步改提示词（本技能不自动拦，靠你自觉）。

## 运镜词（中文）

固定 / 推 / 拉 / 左摇 / 右摇 / 左移 / 右移 / 弧移 / 跟拍 / 主观 / 微晃——与 `storyboard-pass.md` 的枚举一致。

## 说话人与台词

- 台词进镜头行，身份写在台词外（一名年轻女性，压低声音说：……）。
- 画外音：以画外音说（唇形完全闭合）。

## 声音分层

台词/歌声/剧内音乐 → 整体视听描述的镜头行；环境动作声 → 整体音景；配乐 → 非剧情音乐。
