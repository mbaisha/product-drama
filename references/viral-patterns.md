# 带货爆款模式（调研失败时的兜底模板）

当联网扒不到真实爆款（搜不到 / 平台封锁 / 无链接）时，直接用这套成熟的带货短剧模板起结构——不卡在调研上。模板综合抖音带货短视频的通用打法，本技能自研沉淀。

## 通用六段骨架（可直接套）

| 段 | 时长占比 | 标配动作 | 标配台词钩子 |
| --- | --- | --- | --- |
| 钩子 | 0–3s（约 15%） | 运动中给痛点：甩头/泼水/撕包装 | 「别再用 XX 了，越用越 XX」 |
| 冲突 | 3–10s（约 20%） | 放大多人共鸣的困境 | 「我也是换了 N 个才踩坑」 |
| 解法 | 10–15s（约 12%） | 抛出转折/人设 | 「直到遇到这个」 |
| 产品 | 15–30s（约 30%） | 卖点可视化演示 | 「一泵起泡 / 一擦即净 / 实测 XX」 |
| 信任 | 30–40s（约 18%） | 前后对比 / 背书 / 价格锚 | 「第 3 天 vs 第 1 天」「同事实测」 |
| CTA | 40–45s+（约 15%） | 举产品笑对镜头 | 「点左下，今天活动价」 |

## 四类最常爆的钩子（挑一个用）

1. **痛点直击型**：「XX 用久了才知道坑在哪」——直戳已购人群。
2. **反常识型**：「越贵越伤 XX，这瓶 9 块 9 反而救了」——制造认知冲突。
3. **强冲突型**：「室友说我头油得能炒菜」——羞耻感 + 共鸣。
4. **悬念型**：「我用它 7 天，同事问我是不是偷偷去做了」——留完播钩子。

## 三种信任锚点（至少用一种）

- **效果对比**：同一人前后分屏（最稳）。
- **实测背书**：「办公室 5 个人轮流测」。
- **价格锚点**：原价 → 活动价，制造紧迫（「今天下单送替换装」）。

## 节奏铁律

- 前 3 秒必须有运动主体 + 一句钩子，否则 2 秒退。
- 每 3 秒一切，深浅/长短相间，否则 5 秒退。
- 卖点必须「看得见」不是「念得出」。
- 结尾必须有情绪升华 + 明确 CTA，否则转化低。
