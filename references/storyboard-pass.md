# 切镜：把剧本落成可生成的分镜

一次任务切一整支。你拿到写满的 `beats` 工作底稿（每拍的 stage / 动作 / 台词 / 秒数），产出把 `drama.json` 的 `segments` 写满。

分镜机制学自 shuohao-skills/novel-storyboard（段→切→镜头提示词、节拍认领、景别/运镜枚举），但**已去掉 H3 逐字对账锁**——本技能的质量门只查核心项，不要求 `[Shot k]` 切点时刻逐字对账、不要求台词逐字进 `<d>` 块。

## 先分段，再切镜

1. **段 = 一次视频生成调用**，≤ 15 秒，不跨场景（带货短剧通常一镜到底或一个场景，段数少）。按六段时间单元分组，每组 9–15 秒一段。
2. **段内切分镜**，每切 2–5 秒（硬门，质量门 `cut-length`），围着 3 秒打。一段通常 3–5 切。
3. **每切一张分镜图提示词（`frame`，中文直呼产品/人物）** + 一段镜头正文（`shot`，中文通用身份）。

## 硬规则

1. **认领是地基。** 每个分镜声明 `beats:[起,止]`（指向 `beats` 数组的 1 基序号），全场连续区间、不重不漏（质量门 `beat-coverage`）。
2. **秒数是下单不是估算。** 分镜秒数 = 认领节拍秒数之和；段 Σ 分镜 ≤ 15 秒（质量门 `segment-cap`）。
3. **景别中文词进 `frame`**，运镜用 H3 官方词表（Static / Push In / Pan Left / Tracking Shot…）。
4. **`frame` 直呼产品/人物名**（它指向挂上去的参考图）；`shot` 用通用身份（an old ferryman 这类），不写角色名——这是 H3 / Seedance 官方规范。
5. **构图量化进字段**：每镜填 `lens` / `cameraPosition` / `composition` / `eyeline` / `focus` / `stability`；每段填 `blocking`（开场谁在左谁在右、朝向、间距）。

## 导演手感（不设门，但决定像不像专业分镜）

- **3 秒一切是短剧的呼吸。** 深浅相间、长短相间。
- **对话切正反打**，关键动作独立成 2 秒插入特写（一泵起泡值得单独一格）。
- **进场第一切给运动主体**，静物特写开场是死画面。
- **反应镜头免费**：一句重台词后切听者脸 2–3 秒。
- **运镜克制**：固定是默认，推给情绪、拉给收场。

## H3 提示词（可选，不强求逐字对账）

每段可写一条 `h3Prompt`；结构见 `references/h3-prompt.md`。本技能**不逐字对账**——只要提示词非空、含 `[Shot k]` 标记即可，门不拦切点时刻和 `<d>` 块。想接 MiniMax H3 / Seedance 实际生成时再按官方格式精修。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 均匀病 | 每切都是 3 秒中景 | 深浅相间、长短相间 |
| 台词爆仓 | 4.4 秒台词塞 3 秒切 | 加秒或拆切 |
| 换景不换段 | 一段里换场景 | 换景必开新段 |
| 特写失忆 | 产品特写和设定图不像 | 挂产品参考图当锚 |
