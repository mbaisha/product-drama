# 爆款调研：怎么把卖得最好的视频扒下来

本文件是 Stage 1 的操作手册。目标：拿到用户给的参考图 / 卖点 / 几句话之后，找出**同类产品卖得最好的几支视频**，并拆出可复用的结构。

方法论来源：本技能自研；联网手段使用 Agent 的 `WebSearch` / `WebFetch` 工具（原 shuohao-skills 不做竞品调研，这是本技能的新增能力）。

## 三级递进（按用户确认的优先级）

1. **先尝试学习/扒原视频。** 用户给了具体视频链接或明确来源，先尝试打开/获取原片做逐帧学习。
   - 拿到了 → 直接进「拆解模板」做结构拆解。
   - 拿不到（下载失败 / 反爬 / 无链接）→ 进第 2 级。
2. **联网定位爆款 + 结构拆解 + 给来源链接。** 用 `WebSearch` 搜同类产品的高播放/高转化视频（关键词：`产品名 + 抖音爆款 / 带货短视频 / 种草`），用 `WebFetch` 打开可见页面读文案、读评论区共识；能定位到的原视频附上来源链接。拆完进「拆解模板」。
3. **还是不行（搜不到 / 平台封锁）→ 回退到既有带货爆款模式。** 直接用 `references/viral-patterns.md` 里的成熟模板起结构，不卡在调研上。

## 调研产出（写进 research.json）

一次调研产出一份 `research.json`，字段：

```json
{
  "product": "产品名",
  "query": "用的搜索词",
  "sources": [ { "platform": "douyin", "url": "...", "account": "...", "metric": "播放/销量/点赞", "note": "为什么爆" } ],
  "viralBreakdown": [
    {
      "stage": "hook|conflict|solution|product|trust|cta",
      "hookType": "痛点直击/反常识/强冲突/悬念",
      "seconds": "0-3",
      "what": "这 3 秒发生了什么、说了什么",
      "why": "它为什么能留住人"
    }
  ],
  "borrow": [ "可复用的钩子句式", "可复用的冲突设定", "可复用的信任锚点" ],
  "fallback": false
}
```

`fallback: true` 表示走了第 3 级（没扒到真实爆款，用模板兜底），要在汇报里明说。

## 拆解模板（逐段填）

对每一支爆款，按六段拆：

| 段 | 看什么 | 记什么 |
| --- | --- | --- |
| 黄金3秒钩子 | 前 3 秒怎么开场？痛点 / 反常识 / 冲突？ | 钩子类型 + 原话 |
| 放大冲突 | 痛点怎么放大成具体困境？ | 共鸣点 |
| 解法转折 | 怎么引出解法？人设 / 悬念 / 反差？ | 转折方式 |
| 产品登场 | 第几秒出场？卖点怎么演示？ | 出场时机 + 演示手法 |
| 信任锚点 | 用了对比 / 背书 / 价格锚点里的哪些？ | 具体锚点 |
| 升华CTA | 怎么升华情绪、怎么引导下单？ | 升华句 + CTA 话术 |

**关键纪律**：扒的是「结构和方法」，不是抄文案。把对手的钩子句式、冲突设定、信任锚点抽出来当「可复用素材」（`borrow`），但落到自己剧本时要换成用户产品的卖点——这是合规底线。
